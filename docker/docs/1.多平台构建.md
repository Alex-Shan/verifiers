# macOS 上构建多平台 Docker 镜像

## 目标

- **OS/ARCH**: `linux/amd64`, `linux/arm64`
- **镜像版本号**: `v1.4.2`

> Dockerfile 已使用 `ARG TARGETARCH` 适配不同架构（第13行），无需修改。

---

## 步骤 1：启用 buildx 和 QEMU 模拟

```bash
# 创建并使用 buildx builder（支持多平台）
docker buildx create --name multiarch --use

# 启动 builder 并启用 QEMU 二进制模拟
docker buildx inspect --bootstrap

# 验证支持的平台
docker buildx ls
```

> **说明**：QEMU 让 Apple Silicon Mac 可以模拟 `linux/amd64`，Intel Mac 可以模拟 `linux/arm64`。

## 步骤 2：构建并推送多平台镜像

```bash
cd docker

# 单平台
docker build --tag alexshan2docker/harness-env:v0.0.1 .

docker buildx build \
  --platform linux/amd64,linux/arm64 \
  --tag alexshan2docker/harness-env:v0.0.1 \
  --push \
  .
```

> **注意**：`--push` 会将镜像推送到远端 registry。你需要先 `docker login` 登录到目标 registry（如 Docker Hub）。

## 步骤 3：验证多平台镜像

```bash
# 查看镜像的 manifest，确认多平台支持
docker buildx imagetools inspect alexshan2docker/harness-env:v0.0.1
```

## 下载镜像

```bash
docker pull alexshan2docker/harness-env:v0.0.1
```

## 运行容器（交互式）

```bash
docker run -it alexshan2docker/harness-env:v0.0.1
```
